# AndroidRemoteGuard

AndroidRemoteGuard 使用 IPv4 网络为无人值守的 Android 设备提供远程布防、告警和控制。受控端采集移动、实体按键、USB 插拔和心跳；服务端保存记录，通知端通过 Server酱³ 接收告警。

## IPv4 连接要求

同一可信局域网内可以直接使用内网 IPv4 地址。异地使用时，需要为所用功能提供对应方向的路由。

| 功能 | 发起方 → 目标 | 目标地址与端口 |
|---|---|---|
| 心跳、告警、离线补传 | 受控端 → 服务端 | HTTPS，TCP 18761。在 `server_ips` 填写受控端能访问的服务端 IPv4 地址，安装时会写入接收证书。 |
| 布防、撤防、scrcpy 远控 | 服务端或控制电脑 → 受控端 | ADB，TCP 5555。在 `device_ip` 填写受控端 IPv4 地址，并授权控制设备的 ADB 密钥。 |
| 接收推送 | 服务端 → Server酱³ → 通知端 | 服务端和通知端可访问推送服务即可。 |

如果网络只允许受控端主动连接服务端，心跳和告警仍可使用；远程布防开关和 scrcpy 需要反方向也能连接。请将 ADB 监听和防火墙访问权限限制在可信网络及已授权的管理设备，避免向公网或公共 Wi-Fi 开放 5555。

### 可选：用 Tailscale 异地组网

当两端位于不同网络且现场路由器不可配置时，可以让受控端和服务端加入同一 tailnet，并在 `device_ip` 和 `server_ips` 中使用各自的 Tailscale IPv4 地址。这是本项目实测过的一种部署方式。已有可达的 IPv4 局域网或其他可信 VPN 时，可以直接使用现有网络。

## 项目组成

| 部分 | 目录 | 职责 |
|---|---|---|
| 受控端应用 | [android](android/) | 布防开关、移动感应、心跳、断线补传与启动恢复 |
| 受控端 root 模块 | [AndroidGuardModule](AndroidGuardModule/) | 监听实体电源及导航键、USB 线在位状态，并记录充电变化 |
| 服务端 | [server](server/) | TLS 接收、SQLite 日志、本地管理页、系统通知与已读同步、通知端推送、远控 |
| 运维工具 | [tools](tools/) | 受控端配对、Windows 一键连接和管理页 SSH 隧道 |
| 通知端 | Server酱³ 客户端 | 接收服务端转发的告警，客户端由第三方提供 |

**[部署指南与注意事项](docs/deployment.md)** 包含依赖、构建、配置、root 模块安装、首次测试以及无人值守冷启动的锁屏密码要求。

布防时约每分钟发送心跳，服务端默认在 10 分钟后报告失联。撤防时发送最后一次状态确认，随后停止心跳。服务端下发的开关操作收到设备确认后更新页面。历史告警分别显示发生和接收时间。
